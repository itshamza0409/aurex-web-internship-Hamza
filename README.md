## Task Description

For Week 1 of my web development internship, I created a simple personal profile webpage using HTML only.

The webpage includes a header, navigation bar, About Me section, Skills, Education, Contact Form, and Footer.

The main purpose of this task was to practice the basic structure of an HTML webpage and understand how different HTML elements work together.

## Technologies Used

* HTML
* Git
* GitHub

## How to Run the Project Locally

1. Clone the repository:


git clone https://github.com/itshamza0409/aurex-web-internship--Hamza-.git


2. Open the project folder.

3. Open `index.html` in any web browser.

That's it. No additional installation or setup is required.

## Key Learnings

During this task, I learned and practiced:

* Creating the basic HTML document structure.
* Using semantic elements such as `<header>`, `<nav>`, `<main>`, `<section>`, and `<footer>`.
* Creating navigation links.
* Creating lists and forms.
* Using labels, inputs, textarea, and buttons in a contact form.
* Using Git to initialize and manage a local repository.
* Connecting a local project with GitHub.
* Making my first project repository for the internship.

## Difficulties / Blockers

One of the main difficulties was setting up Git and connecting the local project to GitHub in my Linux Mint environment.

I also had to understand how VirtualBox shared folders work when moving project files between Linux Mint and Windows.

After working through these issues, I was able to successfully set up the project and understand the basic Git workflow.
